Ressources graphiques

Charte, logo, fontes, icônes — ce à quoi ressemblent les documents produits par le Documentation Builder. Ressource d'organisation, au même titre qu'une correspondance : deux clients n'ont pas la même identité visuelle. Un gabarit désigne la sienne par brandAssetId.

Les exports de WFD portaient leur charte en dur, et la représentation n'était pas fidèle : une charte écrite dans le code d'un exporteur ne se corrige que par un commit. Elle se corrige ici.
