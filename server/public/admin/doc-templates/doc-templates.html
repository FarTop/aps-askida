Gabarits de document

Un gabarit dit ce qu'un document décrit et dans quel ordre. Il décrit un produit, pas un client : la forme d'un runbook Iconik vaut pour tous ceux qui utilisent Iconik. C'est pourquoi un gabarit peut être partagé — visible de toutes les organisations — ou propre à une seule quand elle a ses exigences.

La ressource graphique qu'il désigne décide de quoi il aura l'air. C'est ce lien qui remplace les chartes écrites en dur dans les exports de WFD.

Contenu (JSON)

Forme libre : c'est le Documentation Builder qui l'interprète, et sa conception n'est pas tranchée. owners est le seul champ déjà lu — il décide quelles lignes de service voient le gabarit (Transverse les voit toutes).
