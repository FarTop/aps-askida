Endpoints

Un Endpoints décrit une suite de requêtes HTTP vers une API partenaire (ex. Publication API) : chaque étape est une requête unique ou une requête répétée par valeur (ex. un réalisateur par film). Objet réutilisable par les workflows, référencé par un nœud Partner.

La connexion se choisit sur le nœud Partner, dans le canevas — cette séquence ne décrit que les étapes, pas où elles s'exécutent (sauf override par étape ci-dessous).
